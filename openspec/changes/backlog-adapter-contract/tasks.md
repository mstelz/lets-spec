## 1. Contract and conformance

The implementation delivers `docs/backlog-adapter-contract.md`, machine-checkable definitions and a reusable offline harness under `contrib/backlog-adapter-kit/`, with tests under `tests/backlog-adapter-kit/`. The production CLI and installed workflow stay unchanged. Use Node's existing test runner and TypeScript toolchain; add the suite to `pnpm test` and the release checks. Each task starts with a failing behavior test where executable behavior is involved. Keep fixtures explicitly labeled as representative simulations, not implementations of the provider API.
